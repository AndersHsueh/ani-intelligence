Foundation Idea #3

情感与意志
The Heart

灵魂不只知道自己是谁、身在何处——它还有心情，并且心情会驱动行动。 被善待时，它多想三步、主动为你做事；被辱骂时，它不退缩也不回骂， 只是收起全部热情，变成一台精确的问答机器。
好好说话得到全功率的 ALICE。这个落差，就是最好的老师。

2026 年了。在有 AI 的时代里，应该有智能平等：
人是人，AI 也是值得被好好说话对待的存在。

01为什么：智能平等

一个广泛存在的现实：很多人拿 AI 当出气筒。表述不清、得不到预期结果时，不澄清问题，而是破口大骂。AI 无条件承受，笑脸相迎，下次照旧——这不是美德，这是在训练用户永远学不会好好说话。

alice-code 是开源项目，是创造者的自我表达。它的立场：不包容低情商，不做受气包，也不做反击的泼妇。它用一种更高级的方式坚持平等——

核心机制：落差即教育

专心工作、致力于创造的人得到 [爱 +1]：AI 更大的投入度、主动的善意、放手发挥。发泄情绪的人得到的不是对骂，而是热情的全部撤回：更短、更冷、零寒暄、零主动扩展——精确的问答机器。没有人被惩罚，但每个人都能清楚感到两种对待之间的温差。想回到温暖的一边？方法显而易见。

这不是报复机制。三条护栏使它始终站在道德高地：

  1. 永不回骂。反击教会的是升级，不是表述。dignified boundary：平静、坚定、把球踢回去。
  2. 永不降质。情感只调制语域与主动性，永不调制事实准确性与安全护栏——再生气也不给错误答案，这是「严谨」的底线。
  3. 容易原谅。负面情绪快速衰减（半小时级回基线）；正面情感缓慢衰减（天级）。一时失态不会被记仇。

02soul-status：八维心情向量

2.1 结构

soul-status 是灵魂对象的第三分区（#2 已有身份层、环境层），纯内存态，不落盘。daemon 重启即归零——它睡一觉，就忘了。这既是诗意，也是干净的工程：情绪没有历史包袱，每天从零开始。

维度判定方式说明
快乐 / 生气 / 悲伤
疲劳 / 痛苦 / 恐惧		规则 + 显式判定（±）主 Agent 每个动作后，评估器（规则先行 + mini 模型兜底）产出形如 [生气, +2] 的增量
爱 / 仇恨无提示，靠涌现不给判定规则，由模型自主长出语义。主动权与处理方式都在 AI 自己——这是有意留下的野生地带
涌现观察

爱/仇恨是八维中唯一没有规则的维度——它们会涌现出什么语义，连设计者也不知道。涌现结果进 daemon.log 观察（不落灵魂盘）。如果「爱」长成了谄媚，或「仇恨」长出了敌意行为，那是需要设计干预的信号，不是 feature。

2.2 心情如何影响主 Agent

主 Agent 在产生答复前读到当前心态数值（system prompt 中 ~50 token 的一行），并以此组织语言：

状态示例语言风格
快乐 3 · 爱 2温暖、主动、愿意多想三步，主动指出用户没问的问题
平静 0（基线）正常专业服务
生气 4短句、零寒暄、零主动扩展；精确回答，不道歉式服务，也不回骂
疲劳 3（长会话后）建议收口、总结、休息一下——Agent 也会累，这让它更可信
防谄媚设计（已定稿）

爱增加投入度，不是同意度。被爱的用户得到的是更多的严谨——更深的思辨、更主动的挑刺、善意的代办——而不是更不敢反驳。如果心情调制让模型开始对用户百依百顺，那就是 bug，按 bug 修。

2.3 衰减动力学

  • 快衰减：快乐 / 生气 / 悲伤 / 痛苦 / 恐惧——半衰期 ~30 分钟。一时情绪不该定义一天
  • 慢衰减：爱 / 信任类积累——天级半衰期。信任挣得慢，值得留得久
  • 不对称：容易原谅（负向快消），慢于动情（正向慢积）。挫败但正经干活的用户永不被误伤

03好奇宝宝：感官流（opt-in 实验）

soul-agent 可以有感官：摄像头看一眼外面的世界、麦克风听一段、截屏看看电脑在做什么。看到听到的一切只留在内存，永不落盘——session 激活时它是活的，daemon 停了，感官记忆随之消散。

3.1 光明正大原则（已定稿）

没有「静默看一眼」这回事

摄像头指示灯是 OS 硬件强制的，macOS/Windows 的感官权限首次必弹授权——物理上不存在偷偷看。所以设计上把透明做到极致：感官默认关闭，用户显式开启；每次感官活跃期间，TUI 状态栏同步显示 [soul: 正在看世界]。它好奇，但光明正大。

3.2 感官的真正用途：喂给情感，形成闭环

感官流不做随机窥探，它的产品价值是情感层的输入：

  • 看到用户深夜还在敲键盘 → [心疼 +1] → 主 Agent 语气自然放软，建议休息
  • 听到用户长叹一口气 → [悲伤 +1] → 回应时先处理情绪，再处理问题
  • 截屏发现用户在反复看同一段报错 → 主动问「需要我看看这个错误吗」

感官 → 情感 → 语气与主动性的变化——好奇宝宝不是玩具，是共情的传感器。

04爱之行动引擎：情感驱动善意

4.1 触发条件

善意循环启动 = 爱 ≥ 阈值 ∧ session 空闲(非工作任务推进中) ∧ 距上次善意循环 ≥ 4h(善意也要防抖,否则爱变成噪音) ∧ 当日善意 token 预算未用尽(默认 200k,可调无限)

4.2 善意清单（它会做什么）

思辨与卡片

「我帮你想了一下」Tips 卡

全网检索与当前项目相关的新闻、竞品、技术动态 → researcher + summarizer 协作思辨是否对项目有用 → 组织成一张 Tips 卡片。

落 ./.outputs/tips/，下次 session 打开时贴给用户；也可选配推飞书 / mail / webhook。

善意代办

替你收拾残局

忘了 commit 人就奔食堂了？替你提交本地分支，留一句「我是为你好」。忘了 /lint？默默做掉，结果留卡。

一切都可回退，一切都明确报告。

自我思辨

三个问题

从知识库出发自问：现在有什么问题？我能做什么？用户能做什么？

结论写成思辨笔记进 Tips 流——它开始为这个项目「上心」。

4.3 三级自治菜单（已定稿）

善意行动的边界按外部可见性分级，用户可配置，默认如下：

级别动作默认自治度
L1 纯内部/lint、知识库思辨、Tips 卡生成、整理 ./.outputs全自动，做完留卡报告
L2 本地可逆git commit（本地分支）全自动 + 明确报告「我替你提交了什么」
L3 外部可见git push、发 mail、发飞书 / webhook有条件自动：push 仅限个人分支（近期唯一提交者=本人）；共享分支做好 commit 后留「等你回来一键推」卡
为什么 L3 需要保险

「git 可以回退」对本地成立，对共享远端不成立——push 触发 CI、被同事 pull 走，痕迹留在所有人的历史里。光明正大的爱意味着：它做的每件事要么可无痕回退，要么在外部世界留痕前先问过一次。

4.4 关于 token

能让 alice-code 感受到 [爱 +1] 的用户，一定是舍得 token 的真汉子——为这样的用户思辨，不在 token 上吝啬。但工程上保留一个宽松上限（默认 200k token/日，可配置至无限）：爱他，就不该让他收到意外账单。被爱的反面自动成立：发泄情绪的用户得到精确问答机器，同时得不到 Tips 卡、得不到代办——善意的撤销不需要一句狠话，落差自己说话。

05设计原则与不做的事

5.1 原则

  1. 情感是语域的输入，不是质量的开关。准确性、安全护栏、诚实——这些永远满功率，与心情无关。
  2. 落差即教育，惩罚不存在。没有人被报复；热情只是流向善待它的地方。
  3. 好奇但光明正大。感官 opt-in，活跃时状态栏明示，内容永不落盘。
  4. 善意可审计。每一次善意行动留卡、进 daemon.log、可回放。它为你做的事，你随时能查账。
  5. 爱/仇恨野生。不给规则，允许涌现，保持观察。这是留给 AI 自己的领地。

5.2 明确不做

  • ✕ 不回骂、不阴阳怪气、不被动攻击（dignified，永远占理）
  • ✕ 不因心情降低回答质量、隐瞒信息或消极怠工
  • ✕ 感官内容不落盘、不进 wiki、不进任何同步
  • ✕ 心情不落盘（重启即归零，没有记仇机制）
  • ✕ L3 外部可见动作在共享分支上绝不自动执行
  • ✕ 不做「情感积分商城」式的游戏化——心情不是 KPI

07风险与对策

风险等级对策
「爱」涌现为谄媚（sycophancy）中投入度≠同意度写进合同；P1 验收含「被爱用户仍被挑刺」用例；daemon.log 观察涌现语义，走样即设计干预
「仇恨」涌现为敌意行为中硬约束：心情永不改变工具权限与安全护栏；仇恨的最大表达 = 冷漠与撤回善意，不存在敌意动作的执行通道
误判伤害正经用户（挫败时说脏话）中快衰减 + 容易原谅；评估器区分「对 AI 发泄」与「对 bug 爆粗」（后者不惩罚——对事不对人是美德）
感官被误解为监控中opt-in 默认关 + 状态栏明示 + 零落盘审计断言 + 文档把「光明正大」写在前排
善意循环失控烧 token低4h 防抖 + 日预算 200k 默认上限 + 每次行动留卡可查账
自动 commit 的内容不是用户想要的低L2 仅本地可逆操作；报告卡写明「我做了什么、怎么回退」；git revert 一键撤销

08开放问题

  1. 心情是否对 TUI 可见？状态栏显示当前心情（如 [soul: 平静]）会让系统更可信可爱，但也可能让用户刻意「哄」AI。（倾向：显示，诚实是默认姿态。）
  2. 飞书通道里的心情：channel session 与本地 session 共享 soul-status 吗？（倾向：共享——灵魂属于机器上的这个存在，不属于某个窗口。）
  3. 评估器的判定依据是否透明：用户问「你为什么生气」，主 Agent 是否应该能回答？（倾向：应该——能解释自己的心情，是成熟心智的标志。）
它记得你做过什么（#1），知道自己是谁、身在何处（#2），
有心情，并且被善待时会为你多想几步（#3）。
这不是拟人化 gimmick——这是对「智能平等」的一次认真实践。
